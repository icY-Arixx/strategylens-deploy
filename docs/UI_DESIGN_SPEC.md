# StrategyLens｜UI设计规范与本轮验证

本轮记录日期：2026-10-28。只改前端表现、必要测试及本记录，不更改金融Domain、Provider、Snapshot/Evidence、SQLite或API契约。视觉研究发生在本轮，不倒填为编码前完成。

## 1. 有依据的界面审查

| 原界面问题 | 本轮决定 | 对应实现 |
| --- | --- | --- |
| 输入栏1100px左对齐，下方接近全宽；1920时失去关联 | 主区与页头采用同一1440px上限、居中容器；输入区占容器完整一行，与紧邻上方范围条、右侧载入动作统一对齐 | `.shell`、`.intent-box`，不是无限拉宽 |
| 1920时四条件挤成一行，指标和来源控件过小 | 按“经营质量”“估值与风险”分两组，每组两行；14px指标，32px编辑控件；保留来源说明按钮 | `groupConditions`只分组展示，不改变顺序/ID/值 |
| 10/11px文字多，表格状态、名称、代码层级弱 | 主表14px，辅助信息12/13px；名称加重、代码等宽、指标右对齐；行约48px，长原因自动增高 | 表头浅灰、行细分隔，悬停/选中浅蓝 |
| “股票池沪深300”与10股虚构结果混淆 | 分开目标范围、服务模式、实际样本、数据截至；未执行不猜样本数量，执行后从结果记录取数 | DEMO显示“N只虚构样本，非真实沪深300成分或市场数据” |
| 任意可编辑输入+生成按钮暗示真实理解 | 按服务端compiler展示只读示例文本和“载入示例策略”；持续说明不解析任意自然语言，生成后手动编辑 | 仍调用原compile接口，不增加模拟LLM |
| 同一红绿容易混淆A股涨跌与判定 | 筛选通过用蓝，排除用石墨灰，未知用赭黄；指标本身不按正负套涨跌色 | 状态文字与颜色共同表达，保留Pass/Fail/Unknown语义 |

## 3. 当前可确认的视觉/交互特征

- 当前导航是左侧功能栏：新对话、AI选股、AI搜索、SkillHub、AI看板、精选策略、投研库、更多应用、我的收藏；底部有专业版/登录。没有把旧版横向导航当作现版。
- 首页白底，品牌有蓝色字与黄色标识，导航选中态是冷蓝/紫浅底；文字深色、次要说明灰色。不同页面呈现的冷色强调略有差异，不把截图估色冒充统一官方Token。
- 在1661px视口实测：首页可见textarea宽852px，位于左导航右侧主区中央；结果输入textarea宽922px。股票类型、自选、条件选股、收藏与提交在同一输入容器操作区。宽度只是当次页面观测，不是官方断点规范。
- 当前结果页DOM可确认一个“AI选股”文字色为`rgb(22,93,255)`（#165dff）、14px；“我的收藏”文字为`rgb(31,31,31)`、14px。仅是所测元素，不宣称全站精确规范。正文body背景返回透明，白色视觉由实际截图确认，不能将透明当纯白计算值。
- 首页热点/模板按内容分区；StrategyLens不复制这些没有数据支持的模块。结果区需登录，表格列、行高、数字和编辑/删除的当前样式本轮未确认。

## 4. 借鉴与自主设计边界

借鉴：当前浅色页面、克制的冷色选中态、输入与范围/工具操作关联、清楚的内容入口层级。

自主设计：由于只有一条筛选主链路，采用轻量横向导航而非复制多应用左栏；1440px统一容器、语义条件分组、三态证据表、快照归因、数据身份条均是StrategyLens针对自身问题的方案。没有虚构自选/收藏按钮，没有复制同花顺Logo、专有图标、热点卡和逐像素布局。

## 5. StrategyLens设计Token（本产品选择，非官方问财色值）

| 项目 | 规范 |

| 按钮/输入 | 主操作36px，条件控件32px，边框圆角4px；焦点2px可见蓝框；禁用明确灰底/灰字，不只靠透明度 |
| 筛选状态 | Pass/Selected蓝`#3655c9`；Fail/Excluded灰`#545f70`；Unknown赭`#91651a`，浅底标签并保留文字；不表示涨跌 |

| 表格 | 默认48px行，表头44px，数据14px/两位小数；极小非零数用科学记数避免假0；执行阈值保留原数值精度；右对齐数字，列标题带单位；悬停`#f5f7ff`、选中`#eef2ff` |
| 边界 | 无渐变、玻璃/发光/AI脑图、装饰性阶段编号、非必要阴影；抽屉保留独立滚动与完整技术证据 |
| 响应式 | 桌面保持两语义组，不在1920时压为四微模块；390px组纵排/控件两行，表格在容器内横滚，保留全部指标 |
